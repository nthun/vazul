# Package index

## Masking functions

Functions for masking categorical values and variable names

- [`mask_labels()`](https://nthun.github.io/vazul/reference/mask_labels.md)
  : Mask categorical labels with random labels
- [`mask_names()`](https://nthun.github.io/vazul/reference/mask_names.md)
  : Mask variable names with anonymous labels
- [`mask_variables()`](https://nthun.github.io/vazul/reference/mask_variables.md)
  : Mask categorical variables with random labels in a data frame

## Scrambling functions

Functions for scrambling values

- [`scramble_values()`](https://nthun.github.io/vazul/reference/scramble_values.md)
  : Scramble a vector of values
- [`scramble_variables()`](https://nthun.github.io/vazul/reference/scramble_variables.md)
  : Scrambling the content of several variables in a data frame
